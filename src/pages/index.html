Quick, accurate tools for the sums these games make you do in your head: where to put a portal, which order to enchant in, how much delta-v a rocket has, when to leave for Duna.

How these tools are made

  • Game version on every page. Each tool says which version of the game its numbers come from, and the date they were last checked.
  • Shown working. Every page explains the formula and walks through a worked example, so you can check the answer and understand it.
  • Tested. The maths behind each tool is checked automatically against hand-worked examples, including every example on these pages.
  • Nothing to install or sign up for. Everything runs in your browser. Seeds, coordinates and designs you type in are never sent anywhere.

Minecraft data: Java Edition 26.3 (and Bedrock where noted). KSP data: version 1.12.5, stock parts and planets. Checked 21 November 2026.
