About {{site_name}}

{{site_name}} is a small set of free calculators for Minecraft and Kerbal Space Program, made by Prime Mover Industries, an independent developer in Australia who plays both games. Each tool answers one question that comes up again and again while playing, and shows how the answer is worked out.

Where the numbers come from

Game rules and figures (enchantment costs, portal search distances, part stats, planet orbits) come from the games themselves, as documented by their player communities and wikis and checked in game where possible. Each page names its sources, the game version and the date the data was last checked. The explanations, examples and code are our own.

Games change. When a Minecraft update changes a rule a tool depends on, the tool is updated and its version line changed. Kerbal Space Program 1.12.5 is the final version of that game, so its data is fixed; mods that change parts or planets aren't covered.

How the tools are checked

All the maths lives in two files (one per game) and is run against hand-worked examples, including every worked example printed on these pages, before each update goes live. If a page's example and its tool ever disagree, that's a bug. Please tell us.
