How the shape is worked out

A block is part of the shape if its centre is inside the circle: (x ÷ r)² + (z ÷ r)² ≤ 1, measured from the middle of the shape to the middle of the block.

For a sphere the same test runs in three dimensions, with the block's height as a third term. For an oval, width and height get their own radius. An outline keeps only the blocks that have an empty neighbour:

  • Thin counts only the four side neighbours, so neighbouring blocks may only touch at a corner. It uses the fewest blocks and looks smoothest from above, but mobs, water and players can squeeze through the diagonal gaps.
  • Thick also counts the four corner neighbours, so every block joins the next one along a face. Use it for walls, tanks and anything that has to hold.

Odd or even width?

An odd width (15, 21, 31) has a single centre block, which is easy to mark and line up with a door or beacon. An even width (14, 20, 32) has its centre on a corner between four blocks, so there are two middle rows. Both are correct; odd widths are easier to build from a centre post.

Worked example: small circles, block by block

A circle 5 blocks wide has radius 2.5, and block centres sit 0, 1 and 2 blocks from the middle. The corner block (2, 2) is √8 ≈ 2.83 from the middle, outside the circle; the block beside it (2, 1) is √5 ≈ 2.24 from the middle, inside. So a filled 5-wide circle is the 5 × 5 square minus its four corners: 21 blocks. The same rule gives 9 blocks for width 3 (a full 3 × 3 square: the corner is √2 ≈ 1.41 from the middle, inside radius 1.5) and 12 for width 4. A hollow sphere 15 blocks wide takes 530 blocks with thin walls (8 stacks and 18 more), 890 with thick walls, and 1,791 filled.

Building tips

  • Start with four markers. Put a block at the centre, then count out half the width in each of the four directions. Build one quarter, then mirror it.
  • Use the heavy grid lines. They are every 5 blocks from the centre, so you can count "5, 10, then 2 more" instead of counting single blocks.
  • For spheres, build the middle layer first. It's the widest one and fixes the size. Then work up and down, a layer at a time, with the layer slider.
  • Domes are the top half of a sphere. With an odd width, the dome includes the middle layer.

The shapes are pure geometry, not game data, so they work in every version. Block counts are checked in this site's tests.
